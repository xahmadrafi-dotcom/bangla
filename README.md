🫡 অবশ্যই।
৶ কোনো আলাদা বর্ণ নয়। এটি বাংলা ইউনিকোডের একটি ভগ্নাংশের প্রতীক।
এর অর্থ:
* ¼ = এক-চতুর্থাংশ (1/4)
* ½ = অর্ধেক (1/2)
* ¾ = তিন-চতুর্থাংশ (3/4)
ঠিক তেমনি,
* ৴ = ১/১৬
* ৵ = ১/৮ (= ২/১৬)
* ৶ = ৩/১৬
অর্থাৎ ৶ মানে একটি সম্পূর্ণ জিনিসকে ১৬ ভাগ করলে তার ৩ ভাগ।
উদাহরণ হিসেবে, যদি একটি রুটি ১৬ টুকরো করা হয়, তাহলে ৶ মানে সেই ১৬ টুকরোর মধ্যে ৩ টুকরো।
Unicode তথ্য:
* চিহ্ন: ৶
* নাম: Bengali Currency Numerator Three
* Unicode: U+09F6
মজার বিষয় হলো, এই ৴, ৵, ৶ চিহ্নগুলো ঐতিহাসিকভাবে বাংলা অঞ্চলে মুদ্রা ও ভগ্নাংশ লেখার জন্য ব্যবহৃত হতো। এখন দৈনন্দিন লেখায় খুব কম দেখা যায়, কিন্তু ইউনিকোডে সংরক্ষিত আছে। 🔮
